Vulnerability research, fuzzing and proof-of-concept validation on
rtw89-win (github.com/Meari-Prototype/rtw89-win), the open-source
Windows 11 ARM64 Wi-Fi/Bluetooth kernel driver I maintain, on the
upstream Linux rtw89 code it reuses, and on my companion Windows
display driver with Miracast support that builds on it, with
coordinated disclosure of upstream findings. Hands-on testing
targets only my own devices and networks.
