# Security Policy

## Maintainer

rtw89-win is maintained by Meari (@Meari-Prototype), who is also its
security contact.

## Reporting a vulnerability

Report privately through GitHub:
https://github.com/Meari-Prototype/rtw89-win/security/advisories/new

Please do not open a public issue for security problems.

## Scope

- This repository's own code (driver, wificx, mac, compat, bt, tools).
- Upstream rtw89 code in `third_party/rtw89/`: report here as well;
  disclosure is coordinated with the upstream Linux rtw89 maintainers.
- Realtek firmware is not covered; report it to Realtek.

## Supported versions

Only the `main` branch. No prebuilt binaries are distributed.
