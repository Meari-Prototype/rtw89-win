# 验证状态

[English](../en/validation.md)

- **适用读者**：使用者和驱动开发者。
- **本文内容**：每个功能的测试条件、结果和数据；哪些功能未测试，以及未测试的原因。
- **前提**：无。

<a id="summary"></a>
## 要点

- 当前源码版本：Wi-Fi 驱动 0.0.11.2，蓝牙过滤驱动 0.1.0.3（构建脚本的缺省版本）。
- 目标设备上实测的最新版本为 Wi-Fi 驱动 0.0.11.2、蓝牙过滤驱动 0.1.0.3。多数项目最后在 0.0.11.1 上实测，两者的差异见[构建](#build)。
- 全部测试均在一台 ROCK 5T 上进行。测试环境见[测试环境](#environment)。
- 通过的站点功能：2.4 GHz（HT20）和 5 GHz（最宽 VHT80）、WPA2-个人、WPA3-SAE 和管理帧保护、A-MPDU 聚合。
- 其它通过的功能：固件错误恢复（SER）、国家码、省电、移动热点、蓝牙补丁下载、BLE 扫描和配对。
- 主要的未测项目：开放网络、隐藏网络、密钥更新、长时间运行、VHT80 下的 WPA3-SAE、多个热点客户端。HE（802.11ax）未实现。见[未测的项目](#untested)。
- 原地升级、`-Country` 参数和缺省工作目录已在目标设备上运行。安装脚本的首次安装路径和 `-WorkDir` 参数只经过语法检查。

<a id="environment"></a>
## 测试环境

全部文档使用下列代号描述测试条件。

| 代号 | 说法 |
|---|---|
| 目标设备 | ROCK 5T（RK3588，M.2 E-key 槽上的 RTL8852BE 模块），Windows 11 IoT Enterprise LTSC 2024 ARM64，版本 26100.9457，测试签名模式 |
| AP-1 | 一台 802.11ac 双频路由器：2.4 GHz HT20，5 GHz VHT80（信道 36），WPA2-个人，无管理帧保护，不支持 HE；信号 −51～−56 dBm |
| AP-2 | 一台 Windows 11 笔记本电脑开启的移动热点：2.4 GHz，WPA2-个人 |
| AP-3 | 一台 Android 平板开启的热点：2.4 GHz，WPA3-SAE 过渡模式（管理帧保护可选），不支持 H2E |
| 客户端-1 | 一台 Android 平板：用作热点客户端和蓝牙对端 |
| 国家码 | JP |
| 固件 | Wi-Fi `rtw8852b_fw-2.bin` 0.29.29.18；蓝牙补丁 `0xdbc6b20f` |

其它条件：

- 测试时 `wificx.sys` 和 `netadaptercx.sys` 的版本为 10.0.26100.9278，KMDF 运行库为 1.35（驱动要求 1.33）。
- 未特别注明时，`Country` 设为 `JP`，其它设置项为缺省值。

吞吐的测量方法：

- 使用 `hosttools\rtw89win-thru.ps1` 经 Wi-Fi 传输一个 32 MiB 或 48 MiB 的文件。两端文件的 SHA256 一致时，结果才有效。
- 单位为 Mbit/s。数据写作"下行 / 上行"：下行指对端发往目标设备，上行指目标设备发往对端。
- 对端：AP-1 时为同一网络中的一台电脑；AP-2 时为开启热点的笔记本电脑；AP-3 和客户端-1 时为 Android 平板。
- 计时包含 ssh 建立连接的时间，因此数值略低于实际传输速度。

表格的读法：

- 矩阵的列固定为：功能、结果、版本、条件、数据。
- "结果"只使用以下词语：

  | 结果 | 含义 |
  |---|---|
  | 通过 | 功能按预期工作。 |
  | 通过（有限制） | 功能可用，但存在"数据"列注明的限制。 |
  | 失败 | 功能未按预期工作。"条件"列注明原因。 |
  | 不支持 | 驱动或硬件不具备该功能。 |
  | 未实现 | 硬件或上游 rtw89 具备该功能，本驱动未实现。 |
  | 未测 | 未经测试。原因见[未测的项目](#untested)。 |
  | 按设计拒绝 | 驱动按设计拒绝该操作。 |

- "版本"为最后一次实测的驱动版本。早于当前源码版本时，加注"（当前版本未复测）"。
- 需要解释时，"条件"或"数据"列链接到[实测结论](observed-behavior.md)的编号。

<a id="limits"></a>
## 已知限制

- 驱动只能安装在 Windows 11 ARM64 26100 及以上版本，并且须打开测试签名模式。
- 驱动只支持 2.4 GHz 和 5 GHz。模块不支持 6 GHz。
- 2.4 GHz 只使用 HT20。5 GHz 最宽为 VHT80。不支持 160 MHz，未实现 HE。
- 支持的安全类型：开放（未测试）、WPA2-个人（CCMP）、WPA2-个人加管理帧保护、WPA3-SAE（AKM 8，CCMP-128，BIP-CMAC-128）。
- 不支持：WEP、TKIP、GCMP、802.1X（企业网络）、OWE、SAE-EXT-KEY、PSK-SHA256（AKM 6）、信标保护、BIP-GMAC 和 BIP-CMAC-256。
- 驱动不缓存 PMKSA，每次连接都执行完整的 SAE。
- 管理帧保护和 WPA3-SAE 缺省关闭（`Pmf=0`）。
- 接收方向不重组分片帧。驱动丢弃分片帧并计数。
- 设置了 `Country` 时，驱动忽略接入点宣告的国家码。
- 未设置 `Country`、也未连接到宣告国家码的接入点时，驱动使用全球通用规则：5 GHz 只被动扫描，也不能开启 5 GHz 热点。
- 定位服务关闭时，`netsh wlan show networks` 等命令报告"拒绝访问"（[SCAN-7](observed-behavior.md#scan-7)）。
- 移动热点只支持 WPA2-个人和 HT20。组主发送方向无 A-MPDU 聚合。
- 能力上报最多支持 8 个热点客户端；只测试过 1 个。
- 驱动不在热点客户端之间直接转发帧；经 Windows 转发的互访未测试。
- 移动热点不使用 HT 保护和 ERP 保护。
- 站点已连接时，热点只能与站点同信道（[HS-12](observed-behavior.md#hs-12)）。
- 有热点客户端时，站点只扫描当前信道。
- SER 或重启设备后，须手动重新打开热点。约 5 分钟没有热点客户端时，Windows 自动关闭热点。
- 国家码为 JP 时，5 GHz 热点只使用信道 36～48。
- 省电的缺省值等同于不省电。驱动无法读取电源计划中无线网卡的省电档位（[PS-2](observed-behavior.md#ps-2)）。
- 连续两次运行未正常结束（包括两次断电）后，网卡显示"已禁用"或消失，直到运行 `rtwdiag.ps1 arm`。
- WPA3-SAE 网络在 SER 后，测试过的接入点（AP-3）无法自动重连，须手动重连；其它接入点未测试（[SEC-4](observed-behavior.md#sec-4)）。
- 蓝牙须另外安装蓝牙过滤驱动。打补丁后，蓝牙侧的共存信息仍然很少（[RTW-12](observed-behavior.md#rtw-12)）。
- 只有 INTx 中断，全部由 CPU0 处理（[PLAT-1](observed-behavior.md#plat-1)）。
- 设备被重新枚举后，芯片在断电前无法下载固件（[INST-6](observed-behavior.md#inst-6)）。本驱动和本项目的脚本不触发重新枚举。
- 诊断接口只对 SYSTEM 和管理员开放。

安装和使用中的限制见[安装与使用](install.md#limits)。术语见[术语表](glossary.md)。
